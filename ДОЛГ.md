# ДОЛГ — что оставляем на будущее

## Безопасность и надёжность
- [ ] Regex в `/purge` без таймаута: «плохой» паттерн может подвесить бота (ReDoS). Нужен лимит длины и выполнение с таймаутом.
- [ ] Нет защиты от абьюза `/purge` (rate-limit на пользователя, подтверждение для больших чисток).
- [ ] Верификация — одна кнопка; нет капчи/вопроса, не защищает от ботов-рейдеров.
- [ ] Бот не проверяет иерархию ролей заранее: при ошибке прав просто молча пропускает выдачу.

## Данные и масштаб
- [ ] SQLite с одним соединением — подходит для десятков серверов; для роста нужен PostgreSQL и миграции (Alembic).
- [ ] Кулдауны XP хранятся в памяти и сбрасываются при перезапуске.
- [ ] Автоочистка: лимит 200 сообщений за проход, раз в 5 минут; старше 14 дней удаляется медленно.
- [ ] Нет бэкапов БД и экспорта данных пользователя.

## Функциональность
- [ ] Веб-панель/дашборд вместо slash-команд для настройки.
- [ ] Магазин ролей/предметов за монеты, инвентарь, налоги и «инфляционные стоки».
- [ ] Больше мини-игр (блэкджек, рулетка, PvP-дуэли), лимиты ставок по серверу.
- [ ] Роли за активность по времени в голосе и по сообщениям за период (сейчас только по уровню).
- [ ] Настройка XP (множители, игнор-каналы), сообщение о повышении уровня — в отдельный канал.
- [ ] Логи: роли, ники, голосовые каналы, фильтры событий.
- [ ] Локализация (сейчас только русский).

## Качество
- [ ] Нет автотестов (покрыть `xp_for_level`, экономику, фильтры `/purge`).
- [ ] Нет CI, Dockerfile и мониторинга.
- [ ] Баланс экономики не проверен на реальных пользователях (гипотеза, см. презентацию).
